# Project Archive

A modern and interactive project showcase platform designed to organize, explore, and present projects in a clean and professional way.

Unlike traditional portfolios, Project Archive focuses entirely on the work itself. It acts as a personal project gallery where visitors can browse projects, filter by technology, search through categories, and explore detailed project pages.

## Features

* Dynamic project showcase
* Advanced search functionality
* Technology and category filters
* Featured projects section
* Dedicated project detail pages
* Automatic project statistics
* Responsive design
* Dark/Light theme support
* Modern animations and transitions
* Project status tracking
* Version history support
* GitHub and Live Demo integration

## Project Status System

* ✅ Completed
* 🚧 In Progress
* 🧪 Experiment
* 📦 Archived

## Built With

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide Icons

## Philosophy

This platform follows a simple principle:

> Don't tell people what you know. Show them what you've built.

Instead of focusing on resumes, certifications, or skill lists, Project Archive highlights real projects, experiments, and development progress.

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
